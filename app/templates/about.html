About This Project

Project Overview

The Sheep Disease Detection System is an AI-powered web application that helps identify common sheep diseases through image analysis. This project was developed as an undergraduate Computer Engineering thesis project.

Technology

  • Model: MobileNetV2 (Transfer Learning)
  • Framework: TensorFlow/Keras
  • Backend: Flask (Python)
  • Frontend: Bootstrap 5
  • Training Images: 833 images (augmented)

Performance

Disease Accuracy
Flystrike 100.00%
Healthy 91.67%
Sheep Scab 90.91%
Orf 90.00%
Ringworm 50.00%
Overall 87.50%
Note: Ringworm's lower accuracy is due to limited training data (37 images). The model maintains 100% precision for ringworm, meaning when it predicts ringworm, it's always correct.

Disclaimer

This system is designed as a supportive diagnostic tool and should NOT replace professional veterinary examination. Always consult a qualified veterinarian for accurate diagnosis and treatment of animal diseases.
